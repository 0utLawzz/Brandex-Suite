# Brandex Suite Branding

## Approved main application — 18 October 2026

The standalone dashboard demo is retired. The operational application uses the approved single Polymnia font, uppercase controls and display text, 100px desktop main headings, 42px section headings, 20px body text and expanded character spacing. Financial summary figures use 50.6px. Mobile headings scale to fit.

Header and footer are adapted from the local Brandex-Client-Ledger source: `index.html`, `ui-enhancements.css`, and `styles.css`. The header preserves Suite navigation and authorization. Footer identifies Brandex Law Associates and the Suite modules. The 220ms page-entry and card/button hover motion follow the Ledger reference and respect reduced-motion preferences. Footers are hidden on printed documents.

## Capital-lock rule

The operational Suite uses uppercase display text across navigation, headings, labels, controls, status tags, report columns, amounts and visible case data. This keeps legal and ledger references visually consistent and helps distinguish similar characters in compact operational views. Stored values, search values and downloaded source data are not changed by this visual rule.
