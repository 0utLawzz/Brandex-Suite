## Capital-lock rule

The operational Suite uses uppercase display text across navigation, headings, labels, controls, status tags, report columns, amounts and visible case data. This keeps legal and ledger references visually consistent and helps distinguish similar characters in compact operational views. Stored values, search values and downloaded source data are not changed by this visual rule.

Reports always use a white paper background and aligned ledger tables. The preview offers two approved sets: **Purple**, using dark purple and purple; and **Ink**, using black with dark-purple detail. Neither set prints a coloured page background.
